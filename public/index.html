🤖 Claude Desktop & Claude Code Configuration

Run this in PowerShell to configure Claude to use your proxy with smart Combos:

[Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "http://localhost:4000", "User")
[Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "YOUR_API_KEY", "User")
[Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "", "User")
[Environment]::SetEnvironmentVariable("ANTHROPIC_MODEL", "auto-fallback", "User")

💻 Cursor / Continue / Cline Setup

  • Base URL: http://localhost:4000/v1
  • API Key: Use any key created in the Accounts & Keys tab (e.g. agp-...)
  • Model Name: Enter any Combo name (e.g. auto-fallback, fast-coding) or model ID (e.g. gemini-3.8-flash-tiered, gemini-2.5-flash)

🐍 Python (OpenAI SDK)

import openai

client = openai.OpenAI(
    base_url="http://localhost:4000/v1",
    api_key="YOUR_API_KEY"
)

# You can use a Combo name like 'auto-fallback' for seamless failover!
response = client.chat.completions.create(
    model="auto-fallback",
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)

🪙 Add Gemini Authentication Cookies

Google requires both session cookies (__Secure-1PSID and __Secure-1PSIDTS) to authenticate Gemini Web models and inject them into Combos.

💡 Quick Steps to copy both cookies from Chrome/Edge/Brave:

  1. Open gemini.google.com and make sure you are logged in
  2. Press F12 (or right-click → Inspect) → click the Application tab (or Storage in Firefox)
  3. In the left sidebar: Expand Cookies → click https://gemini.google.com
  4. Click __Secure-1PSID in the table, copy its Cookie Value and paste in Box 1
  5. Click __Secure-1PSIDTS in the table, copy its Cookie Value and paste in Box 2
By saving session cookies, you confirm that you are authorized to use this session and agree to our Terms of Service and Acceptable Use Policy.
