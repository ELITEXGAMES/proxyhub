3. How Prompts, Messages & Conversations Are Handled

VERIFIED CODEBASE IMPLEMENTATION:
  • No Persistent Prompt Storage: The Proxy does NOT save, store, or log the text content of your prompts, messages, code snippets, or AI completions in the database or analytics store.
  • Ephemeral Processing: Request bodies received on /v1/chat/completions or /v1/messages are held in volatile RAM only for the duration required to transform the request format and stream upstream packets.
  • Log Redaction: Operational console logs explicitly redact message contents by default. Only metadata (model name, streaming status, message array length) is logged.

4. IP Addresses, Logging & Rate Limiter Cache

Rate Limiter Cache: To protect the local instance from abusive traffic, loop conditions, or quota exhaustion, an in-memory sliding window rate limiter monitors client IP addresses. This cache stores the IP address and request count, and is automatically cleared and reset every sixty (60) seconds. It is never persisted to disk.

Server Logs: When the proxy runs in daemon mode or behind logging redirection (via AG_LOG_FILE), the Node.js process writes operational events (such as server startup, token refreshes, and connection status). Internal filesystem paths and credentials (ya29..., AIzaSy..., agp-...) are programmatically redacted via a regex sanitizer before writing to disk.

5. Local Storage & File System Persistence

All persistent state managed by the Service is stored exclusively on the host operating system in the user's home directory:

~/.antigravity-proxy/store.json (Windows: %USERPROFILE%\.antigravity-proxy\store.json)

This design ensures that your data is completely separated from the git repository working tree. If you clone, update, or publicize your git repository, your credentials, keys, and tokens remain secure on your local workstation and are never pushed to GitHub or external source repositories.

6. Third-Party AI Providers & Upstream Data Flows

When you dispatch a request to the Service, the proxy securely transmits your prompt data over encrypted TLS (HTTPS) connections directly to the respective upstream API provider:

  • Google LLC / Alphabet Inc. (Google Cloud & Gemini Web): If targeting Gemini models, prompts are transmitted directly to Google endpoints (daily-cloudcode-pa.googleapis.com, generativelanguage.googleapis.com, or gemini.google.com). Google processes this data pursuant to the Google Privacy Policy and Google Cloud Privacy Notice.
  • NVIDIA Corporation (NVIDIA NIM): If targeting NIM models, prompts are transmitted directly to integrate.api.nvidia.com pursuant to the NVIDIA Privacy Policy.

Zero Developer Telemetry: No copy of your prompt, response, or metadata is ever forwarded to the author or maintainers of Antigravity Proxy.

7. Cookies & Browser Storage Mechanisms

The web dashboard utilizes minimal local storage and browser cookies for session state:

  • ag_token (Browser Cookie / LocalStorage): Stores your active session token for seamless authentication between the browser dashboard and local endpoints.
  • ag_dash_pwd: Used only if a DASHBOARD_PASSWORD is configured in your .env file.
  • No Third-Party Tracking Cookies: The dashboard does NOT use Google Analytics, Facebook Pixel, tracking beacons, advertising cookies, or third-party telemetry scripts.

8. Data Retention, Purging & Deletion Procedures

Because all data is hosted locally under your direct custody, you have complete sovereignty over retention and purging:

  • Purging Analytics: Clicking "🗑️ Clear Analytics" in the web dashboard instantly erases all recorded token counts, model breakdowns, and the 50-item request history.
  • Removing Accounts & Cookies: Accounts and Gemini cookies can be disconnected or permanently deleted at any time from the Accounts tab.
  • Purging Generated Media: You can delete all generated images and videos by clearing the public/media/ directory.
  • Complete Factory Reset: Deleting the ~/.antigravity-proxy/ folder immediately purges 100% of all stored credentials, keys, combos, and logs.

9. Technical & Security Safeguards

The Service implements defense-in-depth security measures to protect data integrity:

  • HTTP Security Headers: Incorporates X-Content-Type-Options: nosniff, X-Frame-Options: SAMEORIGIN, X-XSS-Protection, and strict referrer policies.
  • Input & Payload Validation: Restricts incoming JSON payloads to 50MB and validates schema structures before processing.
  • Credential Masking: Automated sanitization routines redact authorization tokens, paths, and secrets from all error messages and server exception outputs.
  • Token Cryptography: Proxy API keys are generated using cryptographically secure pseudorandom numbers (Node.js crypto.randomBytes).

10. User Rights under DPDPA, 2023 (India)

If you are located in India, you are recognized as a Data Principal under the Digital Personal Data Protection Act, 2023, and possess the following statutory rights regarding your personal data processed by the Operator:

  1. Right to Access Information (Section 11): You have the right to obtain a summary of personal data processed, identities of all third parties with whom data has been shared, and any other relevant information.
  2. Right to Correction & Erasure (Section 12): You have the right to correct, complete, update, and request the erasure of your personal data stored within the Service. You can exercise this directly through the Dashboard or by deleting store.json.
  3. Right of Grievance Redressal (Section 13): You have the right to register grievances with the Data Fiduciary's designated Grievance Officer regarding the processing of your personal data.
  4. Right to Nominate (Section 14): You have the right to nominate an individual to exercise your rights in the event of death or incapacity.
